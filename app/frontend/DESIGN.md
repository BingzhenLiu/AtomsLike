# AtomForge on Atoms — 设计规范

## Direction & Layout

AtomForge 是一个「一句话生成可用小工具」的 AI 产品团队工作台：左侧和 AI 对话并审批方案，右侧立刻预览可交互的应用。产品情绪是**工程控制台（engineering console）**——冷静、精确、可信，像一块随时待命的构建台，而不是消费级聊天玩具。首屏第一个视觉信号：深海军蓝画布上叠着一层极淡的方格蓝图纹理，右侧是灰白棋盘格的预览台面（代表「代码即将出现在这里」）。

- 明确要做：单一深色工作台身份、真实构建阶段的时间线、可切宽的预览台面、审批闸门卡片。
- 明确不做：蓝紫渐变光晕卡片、玻璃拟态堆叠、仪表盘式图标宫格、圆润糖果色插画。
- 视觉参照：现有 AtomForge 深色控制台（`--canvas`/`--panel` 层级 + 等宽工具标签 + 蓝图网格），本次迁移沿用并统一到 Atoms 前端工程中。
- 主视点：右侧结果台面（生成成功后被应用内容占满）。信息层级：导航/模式 > 对话与方案 > Agent 进度 > 版本历史。
- 布局：双栏工作区网格 `minmax(360px, 430px) | minmax(0, 1fr)`，等高满屏，左栏内部纵向滚动，右栏结果区独立滚动。卡片间距 8/10/16/20px 四级，区块内边距 20px（`px-5 py-5`）。
- 内容密度：对话区偏疏（消息气泡 13px / 20px 行高），时间线与版本历史偏密（11px 正文 + 9–10px 等宽标签），保持「控制台」密度而非营销页留白。
- 断点：≥901px 双栏常显；≤900px 切换为 Chat / Result 两枚顶部 Tab 单栏模式，高度 `calc(100vh - 52px)`，导航 52px 固定；≤640px 预览按 100% 宽自适应（仍可手动切 390/768/100% 画布宽度）。

## Tokens

颜色（全部为深色单主题，语义固定）：

- 画布 `--canvas: #07101d`，次级画布 `--canvas-soft: #0a1422`。
- 面层 `--panel: #0d1828`、抬升面 `--panel-raised: #111f32`、静默面 `--panel-quiet: #0a1524`。
- 描边 `--line: #22324a`、强调描边 `--line-strong: #30425e`。
- 文本 `--text: #eef4ff`、次级 `--text-soft: #becbe0`、弱化 `--muted: #8496b1`。
- 主色 `--accent: #8da2ff`、悬停 `--accent-strong: #7089ff`、浅底 `--accent-soft: rgba(141,162,255,.14)`。
- 状态：成功 `--success: #52d6a1`、危险 `--danger: #ff7b8d`、警告 `--warning: #f2be6d`。
- 强调色克制使用：只出现在主按钮、当前阶段图标、激活版本卡与焦点环。冷色蓝紫是开发者工具语境下的有意选择，因此不使用 Orbitron/Exo 类科技字体、不使用发光或渐变描边卡片（避免通用 AI 观感）。

字体（全部为本机栈，页面不请求第三方字体，保证预览台面与生成应用的沙箱环境一致）：

- 正文：`"Avenir Next", Avenir, "Segoe UI", system-ui, sans-serif`，14px / 1.5。
- 标题：同族，600–700 字重，字距 -0.03em–-0.045em，营造压缩的工程感（如首屏 27px、面板标题 14–16px）。
- 工具标签：`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`，9–10px，字距 0.12em，全大写。
- 按钮：12px / 700；正文 13px / 400–600；辅助说明 10–11px / 400。

间距与形状：间距刻度 2 / 4 / 8 / 10 / 12 / 16 / 20 / 28px。圆角：按钮 12px（`rounded-xl`，小按钮 8px）、卡片 12–16px、输入框 16px、头像/圆点全圆、预览台面 14px。整体形状语言偏「面板 + 细描边」，圆角一致，不使用胶囊按钮（状态标签除外）。

层级与深度：以 1px 描边建立层级，阴影只在需要浮起时使用：面板 `0 22px 80px rgba(0,0,0,.22)`、预览纸面 `0 22px 70px rgba(3,8,18,.32)`、输入框 `0 14px 40px rgba(0,0,0,.22)`。浮层与固定元素（移动端 Tab 栏、底部输入区）使用 `rgba(7,16,29,.82)` + 背景模糊。

## Shared Patterns & States

- **工作台外壳**：双栏网格，左栏含品牌头 + 模式徽标、警告条、项目信息、对话/方案/时间线/版本历史，底部固定输入区；右栏为结果台面。禁止把结果区做成分页或弹窗。
- **消息气泡**：用户右侧、AI 左侧；用户 `--panel-raised` 实心，AI `--panel-quiet` + 描边，最大宽度 82%，圆角 16px 且朝向发送方的一角收小（`rounded-tr-sm`/`rounded-tl-sm`）。
- **方案审批卡**：主色描边 + 极浅主色底，展示目标、核心功能、本版不做、我的假设、待确认四组条目；底部为「批准并生成」主按钮与「重新规划」次级按钮；次级按钮为描边样式，禁用时透明度 40%。
- **Agent 时间线**：竖向连线 + 4 个状态圆点（pending 弱化 / active 主色脉冲 / completed 成功 / failed 危险），active 图标旋转。阶段必须由真实请求生命周期驱动，禁止脚本化假动画，禁止展示隐藏思维过程。
- **版本历史**：不可变版本列表，激活项主色描边 + 浅主色底并标注「当前版本」，其余显示「切换」。
- **结果台面**：Preview / Code 分段切换（分段控件为内嵌描边胶囊容器），宽度切换 100% / 768px / 390px，Code 视图顶部浮动「复制 HTML」按钮。空状态、构建中进度条、错误状态都必须可见且可恢复。
- **预览 iframe 安全**：`sandbox="allow-scripts allow-forms allow-modals"`，加上生成时注入的 CSP；禁止添加 `allow-same-origin`。
- **状态**：hover 只做 1px 位移或描边/文字提亮，过渡 150–200ms ease；disabled 用 35–50% 透明度且禁用指针；loading 用阶段时间线 + 顶部 shimmer 进度条；error 用红色描边提示条并保留当前可用版本；空状态说明下一步动作。
- **动效**：脉冲环 1.6s ease-in-out 循环、进度条 shimmer 1.8s linear、预览宽度切换 300ms；`prefers-reduced-motion: reduce` 下全部动画时长降至 0.01ms。
- **无障碍**：可点击目标不小于 28×28px（图标按钮）与 36px（主按钮）；焦点环 `2px solid var(--accent)`、offset 2px；图标按钮必须带 `aria-label`；对比度全部 ≥ 4.5:1（深底浅字、浅主色底深字）；表单错误以文字提示条呈现，不依赖颜色。

## Media

- 本产品是操作型工具界面，主视觉不是图片，而是**真实生成结果的实时预览**与蓝图网格背景，因此不引入摄影或插画素材；抽象渐变与装饰性 SVG 也不作为替代品。
- 生成结果本身即内容素材，占满右侧台面，按 100% / 768px / 390px 三种宽度呈现，不做全幅出血，不加文字叠加。
- 图标统一使用 lucide-react 线性图标（13–24px），与等宽标签共同构成控制台语言。
